2. Cómo rotar el token de Mapbox (paso a paso)

⚠️ Por qué rotarlo: el token actual (pk.eyJ1IjoiYm9hcmRpbmdnYXRlMTEi…) quedó expuesto en el historial de git y en varios ficheros de respaldo del repositorio. Cualquiera que vea el repo puede usarlo (con tu cuota gratuita de Mapbox). Rotarlo revoca el viejo y lo sustituye por uno nuevo.
1
Entra en account.mapbox.com e inicia sesión (el usuario de la cuenta actual es boardinggate11).
2
Ve a Account → Tokens (o «Access tokens»). Verás la lista de tokens pk.… (Default public token y los que hayas creado).
3
Identifica el token expuesto (empieza por pk.eyJ1IjoiYm9hcmRpbmdnYXRlMTEi) → Revocar / Delete.
4
Crea uno nuevo: Create a token. Ponle un nombre (p. ej. «Tesla app»), marca los scopes necesarios: Styles, Fonts, Vision/Tiles, Directions (para el tráfico) y Terrain (para el relieve 3D, si lo usas).
5
En URL restrictions añade tu dominio (p. ej. https://TU_USUARIO.github.io/Tesla/*) para que el token solo funcione desde tu app.
6
Pulsa Create y copia el nuevo token pk.….
7
Pégalo en el panel Keys/API keys de Freebuff (clave mapbox) — Freebuff regenera PNG/zbuildgs.js automáticamente. Y si usas el despliegue de GitHub Actions, actualiza también el secret APP_CONFIG_JSON.
8
Comprueba que todo funciona (mapa, tráfico, relieve) y vuelve a revocar el viejo si no lo hiciste en el paso 3.
✅ Consejo: el token nuevo no debe pegarse en ningún fichero del repo: vive en el panel de Keys (Freebuff) o en el secret encriptado de GitHub.

3. Configuración necesaria (resumen)

  • Fichero de claves: PNG/zbuildgs.js — está en .gitignore y NO se sube a GitHub. Freebuff lo genera desde el panel Keys/API keys.
  • GitHub Pages (para que funcione el sitio publicado sin subir el token):
    1. Settings → Secrets and variables → Actions → New repository secret → nombre APP_CONFIG_JSON, valor = el JSON completo de window.APP_CONFIG (estructura en PNG/zbuildgs.example.js).
    2. Settings → Pages → Source → GitHub Actions.
    3. El workflow .github/workflows/deploy-pages.yml ya está en el repo: genera PNG/zbuildgs.js en el build desde el secret y publica el sitio.
  • Firebase: el proyecto es boardinggate-1df74. Si la base de datos está abierta, cualquiera puede escribir alertas: revisa las reglas de Firestore (solo lectura/escritura autenticada) en console.firebase.google.com.
  • Open Charge Map: clave gratuita en openchargemap.org (nivel «developer»). Solo la usa tesla.html.
